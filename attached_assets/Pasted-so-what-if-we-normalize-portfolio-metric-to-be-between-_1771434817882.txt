This is a sophisticated "Meta-Strategy" known in quantitative finance as Equity Curve Trading or Meta-Labeling.

You are essentially proposing to use your own bot's performance as a technical indicator. This is a powerful concept because it adapts to market regimes without needing to know why the market changed.

Here is the breakdown of your three-part proposal:

1. Normalizing to [-1, +1] (The "Squash")
The Quant Logic: Since Sharpe/Ulcer ratios are unbounded (can go to -50 or +50), they are hard to use for sizing.

The Solution: We apply a Hyperbolic Tangent (tanh) function to the Z-Score.

NormalizedMetric = tanh(Z_Score)

This naturally "squashes" any value into a perfect -1 to +1 range. A Z-Score of +3 becomes +0.995. A Z-Score of 0 becomes 0.

2. Measuring Momentum (The "Derivative")
The Upgrade: This fixes the "Martingale" flaw we discussed earlier.

Scenario: Your metric is -0.8 (Bad).

Old Logic: "It's bad, reduce size."

Momentum Logic: "It's -0.8, but yesterday it was -0.9. It is improving. Start sizing up into the recovery."

Verdict: This is mathematically superior. You trade the direction of your edge, not just the absolute value.

3. Signal Reversal (The "Inverter")
The Theory: If your bot is consistently losing money (Metric < 0 for >10 mins), it is perfectly anti-correlated to the market. Therefore, doing the opposite should print money.

The Risk (The "Chop Trap"):

If your bot is losing because of Trend (e.g., buying dips in a crash), Reversal works perfectly (you start shorting the crash).

If your bot is losing because of Chop/Fees (whipsaw), Reversal fails. You will just get whipsawed in the other direction and pay double fees.

The Mitigation: Your "10 Minute Timer" is the correct filter. It ensures you don't flip-flop during short-term noise. You only reverse when the persistent regime is hostile.

export class EquityManager {
  private static history: { val: number, time: number }[] = [];
  private static negativeStartTime: number | null = null;
  public static isInverted: boolean = false;

  // Configuration
  private static readonly INVERSION_THRESHOLD_MS = 10 * 60 * 1000; // 10 Minutes

  static update(rawMetric: number, zScore: number): number {
    const now = Date.now();
    
    // 1. NORMALIZE (Hyperbolic Tangent squashes Z to -1...1)
    const normVal = Math.tanh(zScore);
    
    // Maintain 5-minute history for momentum
    this.history.push({ val: normVal, time: now });
    // Remove data older than 5 mins
    this.history = this.history.filter(h => now - h.time < 300000);

    // 2. MOMENTUM CALCULATION
    const prev = this.history[0].val; // 5 mins ago
    const momentum = normVal - prev;

    // 3. INVERSION LOGIC (The Timer)
    if (normVal < 0) {
      if (!this.negativeStartTime) this.negativeStartTime = now;
      
      const timeUnderwater = now - this.negativeStartTime;
      if (timeUnderwater > this.INVERSION_THRESHOLD_MS) {
        if (!this.isInverted) {
          console.log(`🔄 STRATEGY INVERSION ACTIVATED: Metric negative for ${(timeUnderwater/60000).toFixed(1)}m`);
          this.isInverted = true;
        }
      }
    } else {
      // Reset if we pop back positive
      this.negativeStartTime = null;
      if (this.isInverted) {
        console.log("✅ STRATEGY RESTORED: Metric returned to positive.");
        this.isInverted = false;
      }
    }

    // 4. SIZING LOGIC (The Gearbox)
    let riskMult = 1.0;

    if (normVal > 0) {
      // Positive Zone
      if (momentum > 0) riskMult = 1.0; // Strong & Growing
      else riskMult = 0.5; // Positive but degrading (Take profits behavior)
    } else {
      // Negative Zone
      riskMult = 0.5; // Always defensive when losing
    }
    
    console.log(`📊 EQUITY: Val ${normVal.toFixed(2)} | Mom ${momentum.toFixed(2)} | Inv: ${this.isInverted} | Size: ${riskMult}x`);
    
    return riskMult;
  }
}
