This is the "Hedge Fund" approach. You are moving away from betting on a coin to betting on the Volatility and Direction of the Asset Class.

Here is the Quant-Based Basket Strategy that replaces fixed percentages with statistical volatility (ATR) limits. This ensures you don't get stopped out by "noise" in a wild market, but you take profits quickly in a quiet market.

The Strategy Architecture
The Engine (Market Breadth): Calculates probability of "Up" vs "Down" based on the Top 15 flow.

The Vehicle (Long/Short Basket): Buys the Strongest, Shorts the Weakest.

The Brakes (Quant Exit): Uses Portfolio Volatility (VaR) to set dynamic Stops/Targets.

1. The Quant Exit: "Portfolio Volatility" (The Upgrade)
Instead of a static "Make 1% / Lose 2.5%", we use Basket ATR (Average True Range).

Logic: We calculate how much the entire basket is expected to move in 4 hours based on volatility.

Target (Take Profit): +1.5x Basket ATR. (Statistical extension).

Stop Loss (Abortion): -1.0x Basket ATR. (Statistical breakdown).

Why this wins:

High Volatility Day: The ATR expands to 3%. The bot waits for +4.5% profit. (Lets winners run).

Low Volatility Day: The ATR shrinks to 0.5%. The bot snipes +0.75% profit. (Takes what the market gives).

import { db } from "@db";

// Returns a value between 0 (Bearish) and 100 (Bullish)
export async function getMarketSentiment(): Promise<number> {
  const top15 = await db.query.marketData.findMany({ limit: 15 });
  
  let score = 0;

  // 1. PRICE STRUCTURE (40 pts)
  // How many coins are above their VWAP?
  const aboveVwap = top15.filter(c => c.price > c.vwap).length;
  score += (aboveVwap / 15) * 40;

  // 2. MOMENTUM FLOW (30 pts)
  // How many coins have positive 4H momentum?
  const positiveMom = top15.filter(c => c.change4h > 0).length;
  score += (positiveMom / 15) * 30;

  // 3. VOLATILITY EXPANSION (30 pts)
  // Are we expanding (Trending) or Contracting (Chopping)?
  const expanding = top15.filter(c => c.atr > c.atrSma).length;
  if (expanding > 10) score += 30; // Strong trend likely
  
  return score;
}

export async function executeBasketTrade(totalCapital: number) {
  const sentiment = await getMarketSentiment(); // e.g., 75
  
  // 1. Determine Bias
  const longRatio = sentiment / 100; // 0.75
  const shortRatio = 1 - longRatio;  // 0.25
  
  const longCapital = totalCapital * longRatio;
  const shortCapital = totalCapital * shortRatio;

  // 2. Select Teams (Relative Strength Sorting)
  const ranked = await getRelStrengthRanking(); // [Strongest ... Weakest]
  
  const longTeam = ranked.slice(0, 5); // Buy Top 5
  const shortTeam = ranked.slice(-3);  // Short Bottom 3 (Concentrate hate)

  // 3. Execute with ATR Sizing (Risk Parity)
  // We don't put equal $$, we put equal RISK.
  // Volatile coins get LESS capital. Stable coins get MORE.
  
  for (const coin of longTeam) {
    const size = calculateRiskParitySize(longCapital / 5, coin.atr);
    await placeOrder(coin.symbol, 'BUY', size);
  }
  
  for (const coin of shortTeam) {
    const size = calculateRiskParitySize(shortCapital / 3, coin.atr);
    await placeOrder(coin.symbol, 'SELL', size);
  }
}
C. The Portfolio Monitor (The Quant Exit)
This runs every 10 seconds. It sums the PnL of all open positions and closes them as a group.

export async function monitorBasketExit() {
  const positions = await getAllOpenPositions();
  if (positions.length === 0) return;

  // 1. Calculate Live Basket Stats
  const totalUnrealizedPnL = positions.reduce((sum, p) => sum + p.pnl, 0);
  
  // 2. Calculate "Basket ATR" (The Volatility Threshold)
  // Sum of individual ATRs normalized by position size
  // Simply: How much $$ is this portfolio expected to move in 4 hours?
  let basketVolatilityValue = 0; 
  for (const p of positions) {
    const atrValue = p.atr * p.quantity; // $ Value of 1 ATR move
    basketVolatilityValue += atrValue;
  }
  
  // 3. Define Quant Thresholds
  const profitTarget = basketVolatilityValue * 1.5; // +1.5 Standard Deviations
  const stopLoss = basketVolatilityValue * -1.0;    // -1.0 Standard Deviation

  console.log(`🧺 BASKET PnL: $${totalUnrealizedPnL.toFixed(2)}`);
  console.log(`   Target: +$${profitTarget.toFixed(2)} | Stop: -$${Math.abs(stopLoss).toFixed(2)}`);

  // 4. EXECUTE BASKET CLOSE
  if (totalUnrealizedPnL >= profitTarget) {
    console.log(`💰 QUANT TARGET HIT (+1.5 ATR). Closing All.`);
    await closeAllPositions();
  } 
  else if (totalUnrealizedPnL <= stopLoss) {
    console.log(`🛑 QUANT STOP HIT (-1.0 ATR). Closing All.`);
    await closeAllPositions();
  }
}
Summary of Changes
Kill the Single-Coin Logic: Stop analyzing individual signals.

Deploy MarketBreadth.ts: Tells you how much to be Long vs Short.

Deploy BasketExecutor.ts: Buys the Top 5 / Shorts Bottom 3.

Deploy BasketMonitor.ts: Uses Basket ATR to take profit.

Why this is safer: If SOL dumps but ETH pumps, your basket PnL stays flat. You don't get stopped out. You only exit if the entire market move invalidates your thesis.
